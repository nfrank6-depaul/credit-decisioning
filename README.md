# credit-decisioning
Evaluating machine learning methods used in credit decisioning. Here models are trained on P2P lending data from LendingTree. Random forest, logistic regression, and XGBoost models are evaluated and compared.

This was a school project done for Machine Learning 1 @ DePaul University in Chicago Illinois on 11-23-25
The reports section contains some maually generated items in excel that assisted me in this project.
In reports you will also find a presentation and a research paper.
In the srce code you will find three .pys. One for each of the models I experimented with. Chat GPT assisted with the debugging of xgboost. Importing a library of the same name and then running that file made things difficult. Thank you Chat.
The environment used to run this code was managed by conda, please see the environment.yml file to run this on your own machine.

Thank you for reading, I hope you learn something from the work I did here.
